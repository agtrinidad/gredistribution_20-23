The Graduate Record Examinations, abbreviated as GRE, is a standardized test required for many Anglophone graduate schools, particularly in the United States and Canada. The test is owned, licensed, and administered by Educational Testing Service, an assessment organization headquartered in New Jersey, United States. ETS provides summary statistics of previous test cycles in order to contextualize scores for users.

This project primarily focuses on the visualization of these test scores, per the statistics provided [under their publically accessible records.](https://www.ets.org/gre/test-takers/general-test/scores/understand-scores.html) Users can inspect distributions for individual intended majors, between majors, or even between user-provided scores and given majors.

Included in repo is the Python-based script [used to OCR scan the provided PDF (Table 3b)](https://www.ets.org/pdfs/gre/gre-guide-table-3b.pdf), clean the ETS-provided data, and transform the dataset into a format more appropriate for visualization through Tableau. Visual assets used in the creation of the project can be found in the repository as well.
